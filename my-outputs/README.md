# Local Outputs

This folder keeps the expected output layout for local runs. Generated files are intentionally ignored by git.

Expected folders:

```text
my-outputs/
├── experiment_cfg/
├── processor/
├── open_loop_eval/
├── mujoco_four_panel_eval/
└── mujoco_four_panel_eval_smoth/
```

Use `final/` for small curated media that should appear in the GitHub README.
